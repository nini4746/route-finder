## Harness: route-finder

**Goal:** A macOS pygame desktop program that generates random perfect mazes up to 1000x1000 cells with the DFS Backtracker algorithm and then visualizes six pathfinding algorithms one at a time finding a path from a randomly chosen point A to point B, coloring every visited cell as the search progresses.

**Trigger:** For route-finder maze-generation, pathfinding-algorithm, and pygame-UI work, invoke `route-finder-orchestrator`. Single-shot questions can be answered directly.
