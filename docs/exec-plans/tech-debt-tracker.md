# Tech Debt Tracker

A running list of known shortcuts, deferred work, and "fix this when we touch it next" items. One row per item.

| Date | Area | Description | Trigger to fix |
| ---- | ---- | ----------- | -------------- |
| (init) | — | No tech debt yet — this is a greenfield repo. | — |

## How to use this file

- Add a row when you knowingly take a shortcut (e.g., "DFS Backtracker hard-coded depth limit at 10000 — revisit if 1000x1000 mazes hit recursion errors").
- "Trigger to fix" is the event that should force the issue back into scope (a failing test, a user complaint, an AC review).
- This file is hand-edited and is NOT regenerated by `--rerender`.

## What does NOT belong here

- Active work plans — those live in `docs/exec-plans/active/`.
- Completed plans — those move to `docs/exec-plans/completed/`.
- Open product questions — those belong in `docs/product-specs/initial-seed.yaml > open_questions`.
